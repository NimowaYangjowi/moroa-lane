# Phase 1: Setup

## 공통 진행 지시사항

- 이 phase가 끝나면 반드시 커밋한다.
- 커밋 전에 동작 확인을 하고, 확인한 명령이나 수동 테스트를 기록한다.
- phase 종료 시 회귀 위험과 개선사항을 리뷰한다.
- 완료한 내용은 `completion-log.md`에 업데이트한다.
- 구현 중 배운 내용 때문에 남은 작업 순서나 범위가 달라지면 이후 phase 문서도 함께 업데이트한다.
- 계획과 실제 구현이 다르면 실제 구현을 기준으로 문서를 고친다.

## 목표

Rails 앱을 만들고, 프로젝트가 채널톡 기술면접용 커머스 시뮬레이션이라는 점을 README 초안에 명확히 적는다.

## 구현 범위

- Rails 앱 생성
- SQLite 설정 확인
- 기본 라우트 설정
- 홈 화면 자리 만들기
- 공통 레이아웃 만들기
- 프로젝트 `README.md` 초안 작성
- seed 데이터 구조를 이후 phase에서 쉽게 넣을 수 있도록 기본 파일 확인

## 사용자 관점 설명

이 phase의 화면은 아직 쇼핑몰처럼 완성되어 보이지 않아도 된다. 사용자가 브라우저에서 앱을 열었을 때 “채널톡 면접용 스킨케어 커머스 시뮬레이터”라는 방향을 알 수 있으면 충분하다.

## 기술 포인트

- Rails 기본 구조를 최대한 유지한다.
- 인증 라이브러리는 아직 붙이지 않는다.
- CSS 프레임워크 도입은 보류한다. 기본 Rails 뷰로 충분한지 먼저 확인한다.

## 검증 방법

- 서버가 로컬에서 실행되는지 확인한다.
- 홈 화면이 브라우저에서 열리는지 확인한다.
- README에 실행 방법과 프로젝트 목적이 적혀 있는지 확인한다.

## 완료 조건

- 로컬 앱이 켜진다.
- 홈 화면이 열린다.
- 프로젝트 루트에 `README.md`가 있다.
- 다음 phase에서 상품 모델과 seed 데이터를 추가할 수 있는 상태다.
