# Phase Review Template

phase가 끝날 때마다 아래 형식으로 `completion-log.md`에 기록한다.

```md
## Phase N: 제목

완료일:
커밋:

### 완료한 것

- 

### 검증한 것

- 

### 회귀 위험

- 

### 개선사항

- 

### 다음 phase 계획 변경

- 변경 없음
```

## 리뷰 기준

- 사용자가 보는 주요 화면이 깨지지 않는가?
- 로그인 전/후 흐름이 예상대로 동작하는가?
- 채널톡에 넘길 고객 속성의 원천 데이터가 명확한가?
- 새 기능이 이전 phase의 데모 흐름을 방해하지 않는가?
- README 또는 phase 문서가 실제 구현과 어긋나지 않는가?
- 다음 phase에서 더 나은 구현 순서가 보이면 계획을 고쳤는가?
